# 分层风格规则

分层图标是 katana-icons 的第二套构造：后片、内容、前片三层叠放，外圈一道描边，颜色全从一个主色推出。
适合导航大类、产品入口、空态插画、营销页，常用 24–96px。界面里跟文字并排的小图标仍用线性四风格（docs/rules.md）。

## 构造

- 48 网格，活动区 4–44，坐标取 0.5 的整数倍。
- 三层：`back` 在最后，颜色最暗；`content` 在中间，近白（亮度 0.96、低彩度），是"装进去的东西"；`front` 在最前，是主色本身。
- 只有 back 和 front 是必需的。没有可抽出的东西就不画 content。
- 每层是闭合轮廓 `d`；层上的细线写在 `lines`（2 单位粗、方头），实心小件写在 `dots`。
- 前片做一个 45° 斜切（左上角或右下角，切 3 格），和标志的垂尾一致。
- 外描边：所有层合起来外扩 1.75（3.5 宽描边压在最底下），只描外圈，层与层之间不描。
- 前片投一道影：前片轮廓上移 1.5、描边色 35%，落在内容上，分出前后。
- 前片顶部一层白色渐变高光（28% → 0），只占上半部分。

## 颜色

全部由 `--ktl-base` 推导（CSS `oklch(from …)`），改一个变量整套换色：

| 用途 | 推导 |
| --- | --- |
| 描边 | 亮度 ×0.32，彩度 ×0.6 |
| 后片 | 亮度 ×0.72 |
| 前片 | 主色本身 |
| 内容 | 亮度 0.96，彩度 ×0.12 |
| 细线墨色 | 亮度 ×0.45，彩度 ×0.8 |
| 座舱灯 | 亮度 0.86，彩度 0.16，色相 +170（主色的对比色） |

## 动作

- 一个图标最多两层会动，动的是"这件东西本身会做的事"：文件夹前片翻开、纸抽出；锁梁抬起；下载箭头下沉；插头右插。
- 动作从 `src/layered.mjs` 的 `L_MOTIONS` 选，时长 260ms，曲线带一点回弹 `cubic-bezier(.2,.9,.25,1.15)`。
- `open` 是"向前翻"：以底边为轴压扁到 0.84 并斜切 −7°，做出透视感；轴心写在层的 `origin`。

## 交付前核对

1. `node scripts/layered-sheet.mjs out/layered.html`，截图看 96 / 56 / 48 / 32 / 24 / 16 六个尺寸。
2. 六个主色并排都要分得清三层；浅色主色（如 #e8e6e1）下前片和内容仍有边界。
3. 悬停一次，动作方向对、停稳。
