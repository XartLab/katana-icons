# katana-icons 绘制规则

所有规则都是硬性的。能量化的由 `node scripts/check.mjs` 检查，其余几条交付前对着截图逐条核对。
这套规则从 KATANA 的标志（后掠 K，ОКБ 设计局方向）推出来：精密仪器、工程制图、苏式航空设备的语义。不照别家图标库的规则改写。

## 1. 画布

- 24 × 24 网格，活动区 2–22，主体最长边至少 12，和同套图标看起来一样大。（check: `live` `size`）
- 坐标与半径只取 0.5 的整数倍。（check: `grid`）
- 只用绝对命令 `M L H V A Z`；曲线只许圆弧，不用贝塞尔。（check: `commands`）

## 2. 线

- 线宽默认 1.5，允许 1–2，跟着旁边文字的字重走；线宽是渲染参数，图形不为某个线宽单独画。
- 线头 `butt`，转角 `miter`。不用圆头、圆角：这套图标的气质是机加工件，不是手写。
- 框体的一个角做 45° 斜切（左上角，切 3 格），就是标志上那道"垂尾"，例如 `M4 7 L7 4 H20 V20 H4 Z`。不是每个图标都要切，有框的才切，一个图标最多切一个角。
- 实心只给小件：省略号的点、柱状图的柱、瞳孔这类。（`fill: true`）
- 任何一段不能短于 1，缩到 16px 会糊；点用 2×2 的实心方块。（check: `detail`）

## 3. 座舱灯

- 每个图标最多一颗灯：2×2 的实心方块，颜色读 `--kti-light`（没设就跟文字色）。（check: `light`）
- 灯默认不亮，`light` 打开才画。用在需要提示状态的位置：通知有新消息、锁已上、工作台在线。
- 灯放在槽里或功能点上，不放在空白处做装饰。

## 4. 动作

- 一个图标只有一个部件会动，做一个动作，做完回原位。（check: `motion`）
- 动作是这个东西本身会做的事：铃摆一下、锁梁抬起、抽屉滑出、旋钮右移、箭头往它指的方向推 2 格。不做和含义无关的弹跳或闪烁。
- 动作从 `src/kit.mjs` 的 `MOTIONS` 里选；缺了就在那里加一个，同时写进 `MOTION_CSS`。
- 时长 180ms，旋转类 320ms，曲线 `cubic-bezier(.2,.8,.2,1)`。位移最多 3 格。
- 原点写在部件的 `origin` 上（默认 12,12），转的东西绕自己的中心或挂点转。

## 5. 四种风格（同一份定义自动出）

| 风格 | 名字 | 做法 |
| --- | --- | --- |
| 单色线性 | `line` | 全部描线，跟文字色 |
| 双色线性 | `line-duo` | 会动的主部件描强调色 `--kti-accent`，其余跟文字色；主次靠这一条分 |
| 线性填充 | `line-fill` | 闭合的外框铺 20% 文字色，线照旧 |
| 单色面性 | `solid` | 闭合的外框填实，落在外框里的细节挖空；剩下的线加粗到 1.3 倍，和填实的图标重量一致 |

- 风格不手画。角色按形状自动判断：有闭合子路径的是"体"，落在最大的体里面的部件和开放线条是"细节"，其余是"线"。
- 想让一个东西在面性里填实，就把它的外轮廓画成闭合路径（`... Z`），细节另起子路径或另成部件。
- 交付前四种风格并排看一遍（自检页 `--sheet` 就是并排的），面性里不能有糊成一团或细节消失的。

## 6. 命名与元数据

- 名字短横线小写，说的是东西本身，不是功能：`trash` 而不是 `delete`。功能词放 `keywords`。（check: `name` `meta`）
- 每个图标写中文名 `zh` 和英文关键词 `keywords`。
- Katana 生态自有的图标以 `kt-` 开头，和界面图标同一套规则。品牌标志只有一个，在 `brand/`，不进图标库。

## 7. 交付前核对（看截图）

1. 48 / 24 / 16 三个尺寸并排，16px 下仍能认出。
2. 和 `chevron-right`、`file`、`lock` 放在一起，粗细、大小、留白一致。
3. 悬停一次，动作方向对，结束停稳。
4. 灯打开时颜色只占一小块，不抢主体。
